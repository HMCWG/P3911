Published work

02 — Standard and reference software

The standard and its reference software

IEEE P3911 is developed in the IEEE C/DC Holographic Media Coding Working Group. i3DV is its reference software, used to implement and validate the tools that enter the standard.

03 — Resources

Documents and reference software

To consult or download the standard documents and i3DV reference software, please use the working group's file management system.

This page links to the papers on their publisher pages; standard documents and reference-software packages are distributed through the working group rather than mirrored here. Proposal numbers and meeting numbers cited elsewhere on this site identify the records to look for in that system.
