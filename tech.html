Technology

Five modules and 27 technique entries from the IEEE P3911 toolset, each mapped to the i3DV reference-software version whose release integration record lists it. Filter the entries by version, or jump to a module.

01 — Modules

What is coded, and in what order

The coded object is a differentiable representation model rather than multi-view video: sparse anchors carry position, features and scale, and an MLP restores full Gaussian attributes at render time. The modules follow that pipeline.

02 — Notes on attribution

How entries are attributed

An entry is attributed to the version whose integration record first lists the tool. Proposal numbers identify the originating document; version numbers give the software release that carries the tool.
